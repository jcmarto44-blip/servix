# SERVIX

Plataforma de chatbots inteligentes para negocios.

## ¿Qué es SERVIX?

SERVIX es una plataforma que permite a cualquier negocio crear su propio chatbot para su web. Ofrece 3 modos:

- 🅰️ **Reglas** — Responde preguntas frecuentes predefinidas
- 🅱️ **Solo IA** — Responde cualquier cosa con inteligencia artificial
- 🅲 **Mixto** — Combina reglas + IA

## Características

- Chat web (widget flotante)
- 3 modos de chatbot
- Panel de administración
- Estadísticas y conversaciones
- Multi-proyecto

## Tecnologías

- **Backend:** FastAPI (Python)
- **Frontend:** HTML + CSS + JavaScript
- **Base de datos:** Supabase (PostgreSQL)
- **IA:** Gemini (Google)
- **Hosting:** Render (backend) + Vercel (frontend)
